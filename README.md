# 📊 Sales & Revenue Intelligence Dashboard

## Overview

An interactive **Sales & Revenue Intelligence Dashboard** developed using **Microsoft Power BI** to analyze sales performance, profitability, regional trends, category contribution, and top-performing products using the Superstore dataset.

## 📈 Key KPIs

- Total Sales: **2.30M**
- Total Profit: **286.40K**
- Total Orders: **5K**
- Average Order Value: **458.61**
- YoY Revenue Growth: **46.9%**
- Profit Margin: **12.47%**

## 📊 Dashboard Features

- Annual Revenue Trend
- Sales by Category
- Regional Sales Performance
- Top 10 Products by Sales
- Interactive Year, Region, and Category filters

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization
- Superstore Dataset

Transformed raw sales data into an interactive business intelligence dashboard for monitoring performance and supporting data-driven decision-making.
